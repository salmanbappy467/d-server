🛠️ স্ক্রিপ্ট ডেভেলপমেন্ট গাইড

MeterNet সিস্টেমের জন্য নতুন অটোমেশন স্ক্রিপ্ট তৈরির নিয়মাবলী ও পদ্ধতি

১. স্ক্রিপ্ট কী এবং কেন?

MeterNet সিস্টেমে প্রতিটি কাজ (যেমন: লগইন চেক, মিটার পোস্টিং) একটি করে আলাদা .js ফাইল দ্বারা নিয়ন্ত্রিত হয়। এই ফাইলগুলোকে আমরা "স্ক্রিপ্ট" বা "প্লাগিন" বলি। আপনি সার্ভারে একটি নতুন স্ক্রিপ্ট আপলোড করলেই সমস্ত ওয়ার্কার পিসি সেটি অটোমেটিক ডাউনলোড করে কাজ শুরু করতে পারে।

২. তৈরির শর্তাবলী (Conditions)

একটি স্ক্রিপ্ট সঠিকভাবে কাজ করার জন্য নিচের শর্তগুলো মানতে হবে:

  • ✅ ফাইলের এক্সটেনশন অবশ্যই .js হতে হবে (যেমন: billing.js)।
  • ✅ স্ক্রিপ্টটি একটি Node.js Module হিসেবে লিখতে হবে।
  • ✅ অবশ্যই module.exports ব্যবহার করতে হবে।
  • ✅ ফাংশনগুলো async (অ্যাসিঙ্ক্রোনাস) হতে হবে যাতে সার্ভার রেসপন্সের জন্য অপেক্ষা করতে পারে।
  • ✅ ওয়ার্কারে ইনস্টল নেই এমন কোনো প্যাকেজ (Dependency) ব্যবহার করা যাবে না। (যেমন: axios, cheerio, fs এগুলো ব্যবহার করা যাবে)।

৩. লেখার পদ্ধতি (Methodology)

MeterNet সিস্টেমটি অত্যন্ত ফ্লেক্সিবল। আপনি দুইভাবে স্ক্রিপ্ট লিখতে পারেন:

পদ্ধতি ১: Direct Function Export (সবচেয়ে সহজ)

সরাসরি ফাংশনের নাম এক্সপোর্ট করুন। API কল করার সময় action প্যারামিটারে সেই নাম দিলেই কাজ করবে।

// billing.js
module.exports.checkBill = async (payload) => {
    return { status: "Paid", amount: 500 };
};
// API Call: { "action": "checkBill" }

পদ্ধতি ২: The `run` Function (স্ট্যান্ডার্ড)

একটি মেইন run ফাংশন এক্সপোর্ট করুন যা রাউটার হিসেবে কাজ করবে। এটি জটিল লজিকের জন্য ভালো।

// billing.js
async function run(payload) {
    if (payload.action === 'PAY') return payBill(payload);
    if (payload.action === 'CHECK') return checkBill(payload);
}
module.exports = { run };

৪. সম্পূর্ণ উদাহরণ (Template)

নিচে একটি আদর্শ স্ক্রিপ্টের টেম্পলেট দেওয়া হলো যা কপি করে আপনি ব্যবহার করতে পারেন।

Template filename: myScript.js 
const axios = require('axios'); // প্রয়োজনে লাইব্রেরি ইমপোর্ট করুন

// ১. হেল্পার ফাংশন (লজিক এখানে লিখুন)
async function performTask(data) {
    console.log("Processing data:", data);
    // এখানে আপনার অটোমেশন কোড থাকবে...
    await new Promise(r => setTimeout(r, 1000)); // ডামি ডিলে
    return { success: true, message: "Task Done!" };
}

// ২. সরাসরি এক্সপোর্ট (Direct Call এর জন্য)
async function specialAction(payload) {
    return { msg: "Special action executed directly!" };
}

// ৩. মেইন রান ফাংশন (Router)
async function run(payload) {
    // অ্যাকশন নেম আপারকেস করে নিন যাতে বানান ভুল হলেও সমস্যা না হয়
    const action = payload.action ? payload.action.toUpperCase() : 'DEFAULT';

    console.log(`▶ Running Action: ${action}`);

    switch (action) {
        case 'DO_TASK':
        case 'TASK':
            return await performTask(payload);
        
        case 'SPECIAL':
            return await specialAction(payload);

        default:
            return { error: `Unknown Action: ${action}` };
    }
}

// ৪. এক্সপোর্ট (অবশ্যই run এবং অন্যান্য ফাংশন এক্সপোর্ট করতে হবে)
module.exports = {
    run,
    performTask,
    specialAction
};

৫. কিভাবে টেস্ট করবেন?

স্ক্রিপ্ট লেখা শেষ হলে নিচের ধাপে এটি সার্ভারে আপলোড ও টেস্ট করুন:

  1. আপনার স্ক্রিপ্ট ফাইলটি (যেমন: myScript.js) সার্ভারের /scripts ফোল্ডারে রাখুন।
  2. অথবা GitHub এ আপলোড করে ড্যাশবোর্ড থেকে "Sync Github" বাটনে ক্লিক করুন।
  3. API কল করুন (Postman বা Dashboard থেকে):
POST /app/myScript
Content-Type: application/json

{
    "action": "TASK",
    "someData": "Hello World"
}
