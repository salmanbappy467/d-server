MeterNet Automation Script: rebpbs.js

এই স্ক্রিপ্টটি MeterNet Distributed System এর একটি প্লাগিন। এটি REB/PBS এর ওয়েবসাইট অটোমেশনের কাজ করে। এর মাধ্যমে আপনি লগইন চেক, মিটার পোস্টিং এবং ইনভেন্টরি চেক করতে পারবেন।

ভার্সন: 2.1.0 (Stable) | আপডেট: ফেব্রুয়ারি ২০২৬

🔗 API Endpoint

যেকোনো অ্যাকশন পারফর্ম করার জন্য নিচের লিংকে POST রিকোয়েস্ট পাঠাতে হবে।

POST /app/rebpbs

Headers:

Content-Type: application/json

🔐 ১. লগইন চেক (Action: CHECK)

এই অ্যাকশনটি ব্যবহার করে ইউজার আইডি এবং পাসওয়ার্ড সঠিক কিনা যাচাই করা হয়। এটি সফল হলে ইউজারের নাম, পিবিএস (PBS) এর নাম এবং জোনাল অফিসের নাম রিটার্ন করে।

Request Payload:

প্যারামিটার টাইপ বিবরণ
action String CHECK, LOGIN, বা VERIFY (বাধ্যতামূলক)
userid String PBS ইউজার নেম (বাধ্যতামূলক)
password String পাসওয়ার্ড (বাধ্যতামূলক)

Example Request:

{
    "action": "CHECK",
    "userid": "dhaka_pbs_1",
    "password": "MySecretPassword123"
}

Success Response:

{
    "success": true,
    "userInfo": "Md. Rahim (AGM)",
    "pbs": "Dhaka PBS-1",
    "zonal": "Savar Zonal Office",
    "cookies": ["ASP.NET_SessionId=...", "auth=..."]
}

📋 ২. ইনভেন্টরি লিস্ট (Action: LIST)

PBS এর স্টোর বা টেস্টিং এ থাকা মিটারের তালিকা দেখার জন্য এটি ব্যবহার করা হয়।

Request Payload:

প্যারামিটার টাইপ বিবরণ
action String LIST, INVENTORY, বা GETINVENTORYLIST
limit Number কতগুলো ডাটা দেখতে চান (যেমন: 50, 100)। ডিফল্ট: 50

Example Request:

{
    "action": "LIST",
    "userid": "dhaka_pbs_1",
    "password": "MySecretPassword123",
    "limit": 10
}

Success Response:

{
    "count": 2,
    "data": [
        {
            "brand": "Hexing",
            "meterNo": "12345678",
            "status": "In Store",
            "cmo": "N/A",
            "date": "05-Feb-2026"
        },
        {
            "brand": "Inhemeter",
            "meterNo": "87654321",
            "status": "Testing",
            "cmo": "CMO-123",
            "date": "06-Feb-2026"
        }
    ]
}

📦 ৩. ব্যাচ মিটার পোস্টিং (Action: POST)

এটি ব্যবহার করে একাধিক মিটার নিরাপদে (একটার পর একটা) আপলোড করা যায়। সার্ভার বিজি থাকলে এটি ব্যবহার করা নিরাপদ।

Meter Object Structure (meters অ্যারের প্রতিটি আইটেম):

প্যারামিটার ডিফল্ট বিবরণ
meterNo - মিটার নাম্বার (বাধ্যতামূলক)
sealNo - সিল নাম্বার (বাধ্যতামূলক)
phase '1' ফেজ (1 or 3)
volt '240' ভোল্টেজ
manufacturerId '581' ব্র্যান্ড আইডি

Example Request:

{
    "action": "POST",
    "userid": "dhaka_pbs_1",
    "password": "pass",
    "meters": [
        { "meterNo": "111111", "sealNo": "S-01" },
        { "meterNo": "222222", "sealNo": "S-02", "phase": "3", "volt": "440" }
    ]
}

Success Response:

{
    "status": "completed",
    "count": 2,
    "failed": 0,
    "data": [
        { "meterNo": "111111", "status": "SUCCESS", "reason": "Saved Successfully" },
        { "meterNo": "222222", "status": "FAILED", "reason": "Duplicate Meter" }
    ]
}

🚀 ৪. ফাস্ট পোস্টিং (Action: FAST)

এটি POST এর মতোই কাজ করে, তবে অনেক দ্রুত (Concurrent)। এটি একসাথে ৫টি করে মিটার সার্ভারে পাঠায়। নেটওয়ার্ক ভালো থাকলে এটি ব্যবহার করুন।

Example Request:

{
    "action": "FAST",  <-- অথবা "CONCURRENT"
    "userid": "dhaka_pbs_1",
    "password": "pass",
    "meters": [ ... অনেকগুলো মিটার ... ]
}

পার্থক্য: সাধারণ POST এ ১০০ মিটার আপলোড করতে সময় লাগে ২০০ সেকেন্ড, FAST মোডে লাগে মাত্র ৪০-৫০ সেকেন্ড।

⚠️ সাধারণ সমস্যা ও সমাধান

  • Login Failed / Dashboard not accessible: ইউজার নেম বা পাসওয়ার্ড ভুল হলে অথবা REB এর সার্ভার ডাউন থাকলে এই এরর আসে।
  • Session Expired: একটানা অনেকক্ষণ কাজ করলে কুকি এক্সপায়ার হতে পারে। স্ক্রিপ্ট অটোমেটিক আবার লগইন করার চেষ্টা করবে না, আপনাকে নতুন রিকোয়েস্ট পাঠাতে হবে।
  • Table not found (Inventory): যদি ইনভেন্টরি পেজে কোনো ডাটা না থাকে, তবে খালি লিস্ট [] রিটার্ন আসবে।
  • Unknown Action: যদি আপনি action প্যারামিটারে ভুল বানান লেখেন। সাপোর্টেড অ্যাকশনগুলো হলো: CHECK, LIST, POST, FAST।
