API Reference

Welcome to the MeterNet Distributed Automation API. This API allows you to offload heavy web automation tasks (like REB Meter Posting) to a network of worker nodes.

Base URL: http://localhost:3000/api
POST /meter-post

Sequential Meter Upload

Uploads a list of meters one by one. This is the safest method for high accuracy.

Request Body

ParameterTypeDescription
userid REQStringREB PBS Username
password REQStringREB PBS Password
meters REQArrayList of meter objects
Example Request
{
  "userid": "dhaka-pbs-1",
  "password": "secret123",
  "meters": [
    {
      "meterNo": "12345678",
      "sealNo": "S12345",
      "reading": "0"
    }
  ]
}
Response
{
  "status": "queued",
  "trackingId": "a1b2c3d4-...",
  "message": "Job added to queue."
}
POST /fast-post

Concurrent Meter Upload ⚡

Uploads meters in parallel chunks (5x speed). Uses token reuse for faster processing.

Note: Request body is identical to /meter-post.

POST /login-check

Verify Credentials

Validates username/password and retrieves Zonal/PBS Office Name.

Example Request
{
  "userid": "dhaka-pbs-1",
  "password": "wrongpass"
}
POST /all-meter-list

Fetch Inventory

Scrapes the PBS inventory list (Store/Issued meters).

ParameterTypeDescription
limitNumberMax meters to fetch (Default: 50)
GET /status/:requestId

Check Job Status

Poll this endpoint to get the result of a queued job.

Success Response
{
  "requestId": "a1b2c3...",
  "status": "completed",
  "progress": {
    "current": 10,
    "total": 10
  },
  "result": {
    "data": [ ...results array... ],
    "failed": 0
  }
}
GET /dashboard-data

Dashboard Statistics

Returns live stats including online nodes, queue count, and daily graph data.
